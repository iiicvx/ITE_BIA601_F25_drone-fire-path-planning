تخطيط مسارات سرب مسيّرات لإطفاء حرائق الأبراج
مشروع لمقرر الخوارزميات الذكية BIA601، الفصل F25، في الجامعة الافتراضية السورية، بإشراف د. عصام سلمان.

يقارن المشروع أربع خوارزميات لتخطيط مسارات المسيّرات في مدن افتراضية بأحجام صغيرة ومتوسطة وكبيرة، مع مراعاة الأبراج والحرائق والطاقة والتباعد بين المسيّرات.
الخوارزميات
- الخوارزمية الجينية GA.
- خوارزمية سرب الجسيمات PSO.
- خوارزمية مستعمرة النمل ACO بنمط MAX–MIN.
- البرمجة الديناميكية DP باستخدام Bellman–Ford.
تُقارن النتائج من حيث جودة المسار والسلامة والاستقرار وزمن الحساب. يوضح التقرير طريقة عمل كل خوارزمية ونتائج المقارنة لكل حجم.
واجهة المشروع
تعرض الواجهة المدينة والمسارات بحركة ثلاثية الأبعاد، وتتيح اختيار الخوارزمية وتغيير زاوية الكاميرا ومتابعة المسيّرة. يعتمد المختبر على نتائج محفوظة، ولا يعيد تشغيل البحث عند تغيير الاختيار.

يتضمن المشروع عشر حالات حافة لاختبار مواقف محددة. ليست كلها مهمات إطفاء؛ ففي بعضها تكون المهمة الوصول إلى الهدف فقط. تظهر مؤثرات إطلاق الكبسولة والإطفاء عند وصول خطة آمنة في مهمة مرتبطة بحريق.
محتويات المشروع
- simulation/: الخوارزميات وإعدادات المدن والتجارب والنتائج.
- backend/: الخادم واختبارات المشروع.
- frontend/: الواجهة والصور والنموذج ثلاثي الأبعاد.
متطلبات التشغيل
- Python 3.10 أو أحدث، ويُفضّل Python 3.12.
- متصفح لعرض الموقع، واتصال بالإنترنت لتثبيت المكتبات أول مرة.
- Node.js مطلوب لاختبارات JavaScript فقط، ولا يلزم لتشغيل الموقع.
تشغيل المشروع على Windows
فك ضغط المشروع أولًا. للتشغيل السريع، افتح backend/Start-Stop.bat؛ يجهّز البيئة ويفتح الموقع. ولإيقافه، شغّل الملف نفسه مرة أخرى.

للتشغيل اليدوي، افتح PowerShell في مجلد المشروع الرئيسي الذي يحتوي backend و`frontend` و`simulation`، ثم نفّذ:
py -3.12 -m venv backend/.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
.\backend\.venv\Scripts\python.exe backend/server.py
الأمر الأول يستخدم Python 3.12؛ إذا كانت لديك نسخة أخرى مدعومة، استبدل -3.12 برقمها. يكفي إنشاء البيئة وتثبيت المكتبات أول مرة، وبعدها استخدم أمر تشغيل الخادم فقط.

افتح http://127.0.0.1:8000 في المتصفح. لإيقاف التشغيل اليدوي، اضغط Ctrl+C في نافذة PowerShell التي تشغّل الخادم.
تجربة قصيرة والاختبارات
نفّذ الأوامر التالية من مجلد المشروع الرئيسي بعد تثبيت المكتبات.

لتشغيل تجربة قصيرة:
.\backend\.venv\Scripts\python.exe -m simulation.experiments --trial
لتشغيل اختبارات Python:
.\backend\.venv\Scripts\python.exe -m pytest -c backend/pytest.ini backend/tests
على Windows يُتجاوز اختبار قياس الذاكرة المخصص لـLinux، وتُتجاوز اختبارات JavaScript المرتبطة بهذه الاختبارات إذا لم يتوفر Node.js.
النتائج المحفوظة
توجد النتائج داخل simulation/results/، ومنها:
- experiments/: نتائج التجارب المرجعية وجداول المقارنة.
- fleet/: نتائج السرب الموسّع.
- special/: نتائج حالات الحافة.
يعرض المختبر النتائج المحفوظة؛ اختيار مدينة أو خوارزمية في الموقع لا يعيد تنفيذ التجارب. لتشغيل التجربة القصيرة، استخدم الأمر الموضّح أعلاه.
